DataVaultServer

Server-side data/session manager returned by DataVaultServer.Open.

Manages ProfileStore sessions, data mutations, replication, observations, and player binding.

Types​

Server​

</>
type Server = {
Name: string,
Template: T,
Mock: boolean,
OnJoin: Types.Signal<Player,
T>,
OnLeave: Types.Signal<Player>,
OnSessionLoaded: Types.Signal<string,
T>,
OnSessionEnded: Types.Signal<string>,

T>
}

The object returned by DataVaultServer.Open.

Functions​

Open​

</>
DataVaultServer.Open(Options: Types.Config<T>) → Server

Opens a new DataVault store.

The returned server object manages ProfileStore sessions, data mutations, replication, observations, and player binding.

LoadSessionAsync​

</>
DataVaultServer:LoadSessionAsync(
Key: string,
Params: Types.SessionParams?
) → Types.Profile<T>?

Loads a ProfileStore session for an arbitrary key.

If a session for the key is already active, the existing profile is returned instead.

Params: Types.SessionParams?
) → Types.Profile<T>?

Loads a player's ProfileStore session.

The player's UserId is automatically added to the profile for ProfileStore's GDPR-related user identification.
