DataVaultServer

Server-side session manager and state factory returned by DataVault.Open on the server.

Key-first API. Prefer State / Player for gameplay reads and writes.

:::danger Type solver required for typed State Typed State<T> / Access<T> requires the new Luau type solver.

Enable Workspace.UseNewLuauTypeSolver = Enabled (or the equivalent Luau LSP setting). Annotate loaded state: 

local S = Server:Explicit(key)

Without the new solver, runtime works but field/method autocomplete will not expand. :::
