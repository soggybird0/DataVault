DataVaultClient

Client-side interface for receiving and observing replicated DataVault data.

DataVaultClient instances are read-only when ClientGuard is enabled. Changes are received automatically from the server through replication.

Open​

</>
DataVaultClient.Open(Options: Types.Config<T>) → Client

Opens or retrieves a client-side DataVault instance.

If an instance for the given store already exists, the existing instance is returned.

Checks whether a path exists within the replicated data.

IsReady​

</>
DataVaultClient:IsReady() → boolean

Returns whether the initial replica has been received.

Observe​

</>
DataVaultClient:Observe(Listener: (Data: T) → ()) → Types.Connection

Observes changes to the entire data object.

The listener is immediately deferred with the current data if the replica has already been received.

ObservePath​

</>

Path: Types.Path | string,
Listener: (Value: any) → ()
) → Types.Connection

Observes changes to a specific path.

The listener is immediately deferred with the current value if the replica has already been received.

Wait​

</>
DataVaultClient:Wait(Timeout: number?) → T?

Waits until the initial replica is received.

If a timeout is provided and expires before the replica arrives, nil is returned.

RequestSync​

</>
DataVaultClient:RequestSync() → ()

Requests a full synchronization from the server.

This is normally handled automatically when the client detects a missing or out-of-order patch.
